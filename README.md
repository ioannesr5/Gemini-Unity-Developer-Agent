# Gemini Unity Developer Agent

![Unity](https://img.shields.io/badge/Unity-Editor-black?style=flat-square&logo=unity)
![Gemini](https://img.shields.io/badge/Gemini-API-blue?style=flat-square&logo=google)

A powerful, modular AI assistant deeply integrated into the Unity Editor, powered by Google Gemini models. It goes beyond simple chat by acting as an autonomous developer capable of modifying scenes, creating UIs, and refactoring C# code via AST parsing.

## 🌟 核心特性 (Key Features)

* **🧠 Smart Context Scanning**: Automatically scans your project's directory structure, active scene hierarchy, and selected GameObjects to provide Gemini with accurate project context.
* **⚡ AST-Based Code Refactoring**: Uses `Microsoft.CodeAnalysis` (Roslyn) to precisely parse and modify existing C# scripts. 
* **🔍 Human-in-the-loop Diff Viewer**: Before applying any code modifications generated by AI, a built-in visual Diff Viewer prompts the developer to review, approve, or reject changes safely.
* **🛠️ Scene & UI Automation**: Instruct the agent to build complex UIs (Canvas, Panels, Buttons), generate Primitive objects, adjust spatial transforms, align bounding boxes, and unpack/modify Prefabs.
* **🚀 Dynamic Model Routing**: Automatically falls back and routes between Gemini Pro and Flash models based on task complexity and availability. Includes support for Gemini Context Caching for large codebases.
* **🚨 Auto-Compile Error Monitoring**: Listens to the Unity Compilation Pipeline to detect C# errors and pass them back to the AI for self-healing suggestions.

## 📦 架构概览 (Architecture)

The tool is built on a clean, decoupled architecture:
* **View Layer**: `GeminiUnityAgentWindow`, `GeminiDiffViewerWindow`
* **Core/Network Layer**: `GeminiNetworkService`, `GeminiModelRouter`, `GeminiCacheManager`
* **Execution Engine**: JSON-based Command Dispatcher (`GeminiCommandExecutorCore`)
* **Domain Handlers**: `FileSystemCommandHandler`, `GameObjectCommandHandler`, `ScriptCommandHandler`, `TransformCommandHandler`

## ⚙️ Installation & Dependencies

### 1. Requirements
* Unity 2021.3 or newer (Recommended)
* Google Gemini API Key

### 2. Required External Libraries
This project relies on **Roslyn (Microsoft.CodeAnalysis)** for Abstract Syntax Tree (AST) parsing. You must install it in your Unity project:
1. Open Unity Package Manager.
2. Add the NuGet package for `Microsoft.CodeAnalysis.CSharp` (You can use [NuGetForUnity](https://github.com/GlitchEnzo/NuGetForUnity) to install it easily).

### 3. Installation
1. Clone this repository or download the source code.
2. Place the `GeminiAgent` folder into your `Assets/Editor/` directory.
3. (Optional but recommended) Create an Assembly Definition (`.asmdef`) for the folder and set the platform strictly to **Editor**.

## 🚀 How to Use

1. **Open the Agent**: Go to the Unity top menu and click `Tools > Gemini Unity Agent (Refactored)`.
2. **Configuration**:
   * Enter your **Gemini API Key** in the configuration panel.
   * Customize the model routing or select a specific model (e.g., `gemini-3.5-flash`).
3. **Context Settings**: Choose what data to share with the AI (Selected Objects, Directory Structure, Scene Context, or Script summaries).
4. **Issue Commands**: Type your instructions in the prompt box (e.g., *"Create a Canvas with a dark panel and a confirm button in the center"* or *"Refactor the PlayerController script to add double jump logic"*).
5. **Approve Changes**: If the AI attempts to modify existing code, the `Diff Viewer` will pop up. Review the changes and click **Approve & Apply** to overwrite and recompile.

## 🛡️ Security & Privacy

* **API Keys** are stored locally on your machine using Unity's `EditorPrefs`. They are never included in the project files or sent anywhere other than the official Google API endpoints.
* Code replacements perform automated backups (`.bak` files) before writing new code to prevent accidental data loss.
